# BMT Group Website

The website of the Bioinspired Robotics and Medical Technology (BMT) Group at The Chinese University of Hong Kong, published with GitHub Pages at [biomedirobotics.com](https://biomedirobotics.com).

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
